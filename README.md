# Network VAPT Lab

## 📌 Overview

This project demonstrates a hands-on Network Vulnerability Assessment and Penetration Testing (VAPT) workflow performed in an authorized and intentionally vulnerable lab environment.

The objective was to identify exposed services, assess vulnerabilities, validate selected findings, and document the security impact and remediation recommendations.

## 🎯 Objectives

- Perform network reconnaissance
- Identify open ports and running services
- Enumerate exposed services
- Identify potential vulnerabilities
- Validate selected vulnerabilities in a controlled lab
- Understand exploitation workflows
- Assess security risk
- Document findings and remediation

## 🧪 Lab Environment

- Kali Linux
- Metasploitable
- Isolated/authorized lab environment

## 🛠️ Tools Used

- Nmap
- Metasploit Framework
- Nessus
- Wireshark

## 🔎 Methodology

### 1. Reconnaissance

Performed initial reconnaissance to understand the target lab environment.

### 2. Port Scanning

Used Nmap to identify open ports and available network services.

### 3. Service Enumeration

Enumerated discovered services to understand the attack surface.

### 4. Vulnerability Assessment

Analyzed exposed services and identified potential vulnerabilities using vulnerability assessment techniques.

### 5. Vulnerability Validation

Used Metasploit in the controlled lab environment to validate selected vulnerabilities.

### 6. Risk Assessment

Evaluated findings based on vulnerability severity and potential security impact.

### 7. Reporting

Documented identified vulnerabilities along with security impact and remediation recommendations.

## 📊 Key Findings

The assessment identified multiple exposed services and potential attack surfaces within the intentionally vulnerable lab system.

Detailed findings will be documented with:

- Vulnerability name
- Affected service
- Severity
- Evidence
- Security impact
- Remediation recommendation
